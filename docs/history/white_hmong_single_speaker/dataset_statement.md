# Dataset statement — no dataset collected

No recordings or private transcripts exist in this repository. Collection is
blocked until the signed-consent, privacy, recording, naming, backup, and
dry-run gates pass.

Planned private dataset: 6–8 accepted hours from `spk01` only, immutable mono
48 kHz/24-bit masters, reviewed transcripts, derived 16 kHz model audio, and
fixed 90/5/5 splits by normalized prompt hash and feature group. Distribution
is not assumed. Variety, inventory, prompt coverage, normalization, and
evaluation equivalences require native validation **[NV]**.
