# Historical single-speaker White Hmong TTS project

These files preserve the original recording, consent, private-data, training,
model, and native human-evaluation plans for historical context. They are not
active workbench requirements and must not be executed as current instructions.

The exact pre-rescope repository is preserved on the local branch
`archive/white-hmong-single-speaker-tts-v0.1` at commit
`fd1756485b1e1b75fd1efee5e37519fa8e255415`. That branch is the authoritative
layout if an old relative link in these moved documents no longer resolves.

Historical material includes:

- the original project plan and Phase 0 status;
- consent, privacy, recording-readiness, speaker-role, and private-data plans;
- the planned dataset, untrained model card, architecture, and threat model;
- data, model, training, and native-listener evaluation configurations;
- Phase 1 governance and target-machine handoff instructions.

Nothing in this directory establishes White Hmong support or resolves a native
validation item. NV-001 through NV-008 remain deferred **[NV]**.
