# Model artifact license status

No project-trained checkpoint exists. The workbench registry currently
references public English and Vietnamese MMS checkpoints under CC BY-NC 4.0 for
scoped local non-commercial inference.

The workbench does not redistribute, bundle, publish, or upload third-party
weights. Model downloads occur only in a separately authorized inference
milestone and remain outside Git.

Any future redistribution requires a repeated license/lineage audit, explicit
project decision, correct attribution, and compliance with the exact upstream
terms. No White Hmong checkpoint or capability is registered.

The authoritative audit is [`docs/license_matrix.md`](docs/license_matrix.md).
