# Model artifact license status

No project-trained checkpoint or model weights exist, and none are licensed for
distribution. The provisional MMS initializations are CC BY-NC 4.0 and restrict
the project to non-commercial research/portfolio use. Fine-tuned derivatives
must retain applicable upstream restrictions.

Do not publish, upload, or distribute weights without all of the following:

- explicit speaker consent for weight distribution;
- a repeated license/lineage review;
- a documented model-release decision;
- a misuse and withdrawal review.

The authoritative audit is [`docs/license_matrix.md`](docs/license_matrix.md).
